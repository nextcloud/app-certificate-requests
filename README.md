# Compact Calendar Widget

Keep an eye on your appointments.

## ✨ About

### Compact Calendar Widget is a Nextcloud Dashboard Widget

Displays upcoming appointments filtered by week, month, or year in the Nextcloud dashboard through mini-calendar views.

## ⚙️ Usage

- It is recommended to download or install this app directly from the [Nextcloud App store](https://apps.nextcloud.com/apps/compact_calendar_widget).
- Alternatively you can download the [latest appstore_switcher release](https://github.com/zomtec2311/compact_calendar_widget/releases) based on this repository.
