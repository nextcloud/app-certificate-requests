# AGENTS.md

Rules for AI coding assistants helping someone request an app certificate.

- Read and follow the [App Store documentation on obtaining a certificate](https://nextcloudappstore.readthedocs.io/en/latest/developer.html#obtaining-a-certificate) and the [Nextcloud AI Contribution Policy](https://github.com/nextcloud/.github/blob/master/AI_POLICY.md). They are the reference; this file does not replace them.
- Use [.github/pull_request_template.md](.github/pull_request_template.md) as the PR body and keep its whole content. Fill it in without removing, rewording or replacing anything. Leave the DCO checkbox for the human to tick.
- Never add `Signed-off-by:` yourself. The human must sign off every commit with their own name and email, matching the commit author, for example with `git commit -s`.
